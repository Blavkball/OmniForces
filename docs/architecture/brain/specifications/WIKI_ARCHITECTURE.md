Version:
1.0

Status:
Architecture Draft

Source of Truth:

AI_Workstation is the master company documentation system.

This document defines the Wiki subsystem of the OmniForces Brain.

---

# Purpose

The Wiki is the structured knowledge layer of OmniForces.

Its responsibility is to transform preserved information into organised, searchable and connected knowledge.

The Wiki never replaces Raw.

It builds knowledge from Raw while maintaining complete traceability back to the original source.

---

# Core Principle

> Raw preserves information. Wiki creates understanding.

The Wiki exists to make information useful without altering the original evidence.

---

# Responsibilities

The Wiki must:

- Organise information automatically.
- Build structured knowledge.
- Generate documentation.
- Maintain relationships.
- Support AI reasoning.
- Support human understanding.
- Keep information searchable.
- Maintain complete traceability.

The Wiki does not:

- Replace Raw.
- Modify original information.
- Execute tasks.
- Store temporary memory.
- Make autonomous decisions.

---

# Automatic Organisation

The user should never manually organise information.

When new information enters Raw, the Wiki automatically determines:

- Projects
- Topics
- Documents
- Atomic Tasks
- Decisions
- Meetings
- Research
- Ideas
- Bugs
- Features
- People
- Technologies

Classification may improve over time as additional information becomes available.

---

# Wiki Pages

The Wiki generates structured pages including:

- Project Pages
- Architecture Pages
- Component Pages
- Person Pages
- Technology Pages
- Decision Records
- Research Pages
- Meeting Summaries
- Task Summaries
- Knowledge Articles

Additional page types may be added in future versions.

---

# Page Structure

Every Wiki page contains:

```
Wiki ID
Title
Purpose
Summary
Related Projects
Related Components
Related Atomic Tasks
Related People
Related Technologies
Related Documents
Related Decisions
Related Raw Records
Last Updated
Generated By
```

# Relationships

The Wiki maintains relationships between information.

Examples include:

- Project → Components
- Project → Documents
- Project → Tasks
- Task → Decisions
- Decision → Evidence
- Person → Projects
- Technology → Components
- Component → Documentation

Relationships are generated automatically.

---

# Traceability

Every Wiki page must reference its originating Raw records.

A Wiki page may reference one or many Raw records.

Every generated statement must be traceable to preserved evidence.

---

# Search

The Wiki provides structured search across:

- Projects
- Components
- Tasks
- Documents
- Decisions
- Technologies
- People
- Knowledge Articles

Search results should prioritise relevance while preserving links to original evidence.

---

# Cross-Linking

The Wiki automatically creates links between related knowledge.

Examples:

- Related projects
- Shared technologies
- Common decisions
- Similar tasks
- Architecture dependencies
- Shared documentation

Cross-links improve navigation without changing original information.

---

# AI Workforce Integration

The Wiki supplies structured knowledge to:

- Supervisor
- Agent Manager
- Atomic Task Engine
- AI Employees
- Resume Engine

The Wiki supports decision making but does not authorise execution.

---

# Documentation Generation

The Wiki may generate:

- Project summaries
- Technical documentation
- Architecture documentation
- Progress summaries
- Knowledge articles
- Status reports

Generated documentation always references preserved evidence.

---

# Updating

Wiki pages may be regenerated whenever:

- New Raw information is received.
- Relationships change.
- Knowledge improves.
- New projects are created.
- Existing information expands.

Regeneration never changes the original Raw records.

---

# Quality Requirements

The Wiki must:

- Remain accurate.
- Avoid duplicate knowledge.
- Preserve traceability.
- Keep relationships current.
- Present information clearly.
- Support future AI continuation.

---

# Future Expansion

Future versions may include:

- Semantic search
- Knowledge graphs
- Automatic timeline generation
- Dependency visualisation
- Multi-project analysis
- Intelligent recommendations
- Context-aware summaries

These features extend the Wiki without changing its core responsibilities.

# Final Principle

> The Wiki transforms preserved information into organised knowledge. Every page, relationship and summary is automatically generated from Raw while maintaining complete traceability to the original source.
